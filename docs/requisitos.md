# 📋 Requisitos do Sistema — JobMail

## 1. Objetivo

Desenvolver uma solução para organizar e gerenciar e-mails relacionados a oportunidades profissionais, facilitando o acompanhamento de vagas e processos seletivos.

## 2. Problema identificado

A grande quantidade de e-mails recebidos durante a busca por oportunidades profissionais pode dificultar a organização das informações, o acompanhamento de prazos e a identificação de mensagens importantes.

## 3. Requisitos funcionais

- RF01: Permitir o registro de informações dos e-mails.
- RF02: Organizar mensagens por empresa.
- RF03: Classificar oportunidades por palavras-chave.
- RF04: Permitir o acompanhamento de processos seletivos.
- RF05: Registrar prazos e ações de acompanhamento.
- RF06: Disponibilizar uma interface para consulta e gerenciamento.

## 4. Requisitos não funcionais

- RNF01: Interface simples e intuitiva.
- RNF02: Organização estruturada dos dados.
- RNF03: Proteção de informações pessoais.
- RNF04: Facilidade de manutenção e expansão.
- RNF05: Automatização de tarefas repetitivas.

## 5. Ferramentas previstas

- Gmail
- Google Sheets
- Google AppSheet
- Google Apps Script

## 6. Status

Documento inicial de requisitos. Os requisitos poderão ser ajustados durante o desenvolvimento e validação do projeto.
